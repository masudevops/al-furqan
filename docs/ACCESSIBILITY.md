# Accessibility

Target WCAG 2.2 AA: semantic landmarks and headings, keyboard-operable navigation/settings, visible focus, high-contrast semantic tokens, reduced motion, responsive reflow, scalable Quran/translation text, meaningful labels, and stable loading/error states. Arabic Quran text declares `lang=ar`, `dir=rtl`, and automatic translation protection.

Before release, test VoiceOver and NVDA, 200%/400% zoom, forced colors, keyboard-only flows, dialog focus trapping/restoration, and target sizes. The settings panel currently has dialog semantics but needs a production focus-trap audit.
