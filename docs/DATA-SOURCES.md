| Feature | Provider | Purpose | License/storage/update | Status |
|---|---|---|---|---|

| Tajweed annotations | Quran.Foundation Content API v4 `text_uthmani_tajweed` | Color-rule lens over verse, structural, and Mushaf page reading | Same Quran.Foundation Developer Terms; fetched with each verse, sanitized to documented Tajweed rule tags/classes, and covered by the short public-content cache above | Active; Mushaf Tajweed preserves official page boundaries while exact QCF physical line rendering remains a separate mode |
| Official Mushaf rendering | Quran.Foundation Content API page data and official QCF V2 per-page fonts | Exact page/line/glyph view | Same Foundation terms; remote per-page font; no inferred page layout; no permanent offline Quran cache | Active |
| Translation footnotes, chapter information, Ayah-linked Hadith and published Answers | Quran.Foundation Content API v4 | Sourced reading context and study references | Same Foundation terms; provider HTML is sanitized; no generated substitute; cache at most one week | Active |
| Quran Reflect Lessons & Reflections | Quran.Foundation Content API v4 Quran Reflect feed | Curated QDC lessons and reflections linked to exact Ayahs | Same Foundation terms; read-only QDC-curated English feed; provider HTML sanitized; comments excluded | Integration active; production `post.read` scope is OWNER CONFIRMATION REQUIRED |
| Quran resource catalog | Quran.Foundation Content API v4 resources | Dynamic languages, translations, Tafsir, recitation styles, and verse-media discovery | Same Foundation terms; fetched dynamically; no corpus stored | Active |
| Search | Quran.Foundation Search API | Quran search | Same Foundation terms; `search` application-token scope | Active; owner reported production and pre-live approval on 2026-08-09 |
| User Quran data | Quran.Foundation User APIs | Bookmarks, notes, collections, goals, preferences, reading sessions | OAuth consent and approved scopes; private server session; user revoke/delete support required | Owner reported scope approval on 2026-08-09; signed-in sync UI and deployed end-to-end validation remain |
| Hadith / Sunnah | Sunnah.com access requested; no approved runtime provider yet | Public Sunnah browsing | sunnah.now declined for single-collection coverage; UmmahAPI held as a fallback because it wraps fawazahmed0/jsDelivr and does not name grading authorities; never infer grades or substitute content | Disabled while the owner awaits Sunnah.com access |
| Prayer calculation, calculated Hijri date, and Qibla bearing | AlAdhan API v1 | Daily/monthly Salah times, countdown, methods, Asr school, Qibla direction | No key; daily browser cache for times; calculated Hijri date is not presented as a moon-sighting declaration | Active |

| Adjustable Hijri display date | UmmahAPI Hijri conversion | Calculated Hijri date with a locally persisted −2 to +2 day display adjustment | No key; response revalidated daily; explicitly not presented as a verified moon-sighting declaration | Active |

| Dua and dhikr | `fitrahive/dua-dhikr` public API | Arabic, transliteration, English translation, practice notes, and source references | MIT; same-origin proxy; upstream responses revalidated daily; attribution displayed; no published public-host SLA or rate limit | Active; live English Vercel host verified 2026-08-09; current catalog is limited to five English categories |
| Dua audio | Hisnul Muslim item-level Arabic recordings | Optional playback only when the recording was matched to the displayed Arabic; ambiguous and variant recordings are omitted | No separate audio license is published; streamed from the source over HTTPS, never copied or cached by Al-Furqan; source retains its rights | Interim direct-stream integration; replace or obtain written permission if the source changes its terms |
| Mosque listings | OpenStreetMap via Overpass API | Nearby places tagged `amenity=place_of_worship` and `religion=muslim` | OpenStreetMap data is ODbL; attribution displayed; public Overpass fair-use; server cache one hour and browser session cache; no bulk/offline copy | Active; completeness varies by community coverage |
| Manual place search | OpenStreetMap Nominatim | Convert user-entered city/country to coordinates | ODbL data and Nominatim usage policy; identifiable User-Agent; daily server revalidation; no autocomplete or bulk queries | Active |

There is no mystery or LLM-generated religious content in the production path.
