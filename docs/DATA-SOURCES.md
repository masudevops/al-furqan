# Data source registry

| Feature | Provider | Purpose | License/storage/update | Status |
|---|---|---|---|---|
| Quran, translations, Tafsir, word-by-word, structure, Ayah recitations, synchronized chapter audio/timestamps, metadata | Quran.Foundation Content API v4 and Quran CDN URLs returned by the API | Authoritative Quran experience, memorization playback, and source-timed word highlighting | Developer Terms; display in app, unmodified Quran; cache at most one week unless expressly permitted; refresh from API; source attribution required; never infer missing timestamps | Active |
| Tajweed annotations | Quran.Foundation Content API v4 `text_uthmani_tajweed` | Color-rule lens over verse, structural, and Mushaf page reading | Same Quran.Foundation Developer Terms; fetched with each verse and sanitized to documented Tajweed rule tags/classes | Active; Mushaf Tajweed preserves official page boundaries while exact QCF physical line rendering remains a separate mode |
| Official Mushaf rendering | Quran.Foundation Content API page data and official QCF V2 per-page fonts | Exact page/line/glyph view | Same Foundation terms; remote per-page font; no inferred page layout; no permanent offline Quran cache | Active |
| Search | Quran.Foundation Search API | Quran search | Same Foundation terms; `search` application-token scope | Adapter and UI active; production scope approval required |
| User Quran data | Quran.Foundation User APIs | Bookmarks, notes, collections, goals, preferences, reading sessions | OAuth consent and approved scopes; private server session; user revoke/delete support required | Owner confirmation required |
| Hadith | Sunnah.com API planned | Browse/search Arabic + English records with references and grades | API key and production terms pending | Disabled at navigation, UI, and API route layers; do not enable until Sunnah.com integration is verified |
| Prayer calculation, calculated Hijri date, and Qibla bearing | AlAdhan API v1 | Daily/monthly Salah times, countdown, methods, Asr school, Qibla direction | No key; daily browser cache for times; calculated Hijri date is not presented as a moon-sighting declaration | Active |
| Dua and dhikr | `fitrahive/dua-dhikr` public API | Arabic, transliteration, English translation, practice notes, and source references | MIT; same-origin proxy; upstream responses revalidated daily; attribution displayed; no published public-host SLA or rate limit | Active; live English Vercel host verified 2026-08-09; current catalog is limited to five English categories |
| Dua audio | Hisnul Muslim item-level Arabic recordings | Optional playback only when the recording was matched to the displayed Arabic; ambiguous and variant recordings are omitted | No separate audio license is published; streamed from the source over HTTPS, never copied or cached by Al-Furqan; source retains its rights | Interim direct-stream integration; replace or obtain written permission if the source changes its terms |
| Mosque listings | OpenStreetMap via Overpass API | Nearby places tagged `amenity=place_of_worship` and `religion=muslim` | OpenStreetMap data is ODbL; attribution displayed; public Overpass fair-use; server cache one hour and browser session cache; no bulk/offline copy | Active; completeness varies by community coverage |
| Manual place search | OpenStreetMap Nominatim | Convert user-entered city/country to coordinates | ODbL data and Nominatim usage policy; identifiable User-Agent; daily server revalidation; no autocomplete or bulk queries | Active |

There is no mystery or LLM-generated religious content in the production path.
