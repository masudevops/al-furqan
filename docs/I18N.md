# Interface languages

**Status:** Preview. Interface text in Arabic, Urdu, Bengali, Indonesian, Turkish and French is a draft written with AI assistance and is **awaiting native-speaker review**. The language picker says so. Religious content is never translated by us.

## How it works

- `src/i18n/locales.ts` lists each language, its direction, and the Quran.Foundation content language it maps to.
- `t("English text")` returns the active language's text from `src/i18n/messages/<code>.ts`, or the English text if a phrase is not translated yet. Placeholders use `{name}`.
- The app shell keeps the language (`af-locale` in local storage), sets `<html lang dir>`, and remounts its tree when the language changes. Server-rendered text stays English until the page hydrates.
- In right-to-left languages, each text element takes its direction from its own first letter (`unicode-bidi: plaintext` in `globals.css`), so English names and untranslated text stay readable. Translation blocks use `dir="auto"`.

## Content in each language (sources only)

Choosing a language switches content to sourced versions; where a source has none, the current choice stays (usually English):

| Content | Source | Languages |
|---|---|---|
| Quran translation | Quran.Foundation | Every language here except Arabic (Arabic readers keep their choice) |
| Tafsir | Quran.Foundation | Arabic, Urdu, Bengali (none in Indonesian, Turkish, French) |
| Word-by-word meanings | Quran.Foundation `language` parameter | Urdu, Bengali, Indonesian, Turkish, French (Arabic uses English) |
| Hadith | fawazahmed0/hadith-api has Bengali, French, Indonesian, Turkish, Urdu editions | Not wired yet (planned) |
| Dua | dua-dhikr | English and Indonesian only (not wired yet) |

## Adding or reviewing a translation

1. Edit `src/i18n/messages/<code>.ts`; keys are the exact English text.
2. `npm test` fails if a phrase used in the code is missing in any language or a placeholder is dropped (`src/i18n/i18n.test.ts`).
3. Once a native speaker has reviewed a language, record it here and remove "preview" for that language.
