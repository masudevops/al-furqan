# Implementation plan

1. Foundation and vertical slice: official starter, docs, design system, Home, full Surah library, reader, themes, sizes, last-read, errors, validation.
2. Core Quran MVP: dynamic translation resource selector, localization/RTL UI, search UI, stronger Arabic/Quran font integration, pagination/long-Surah performance, local bookmarks.
3. Quran audio and study: reciter discovery/player, Tafsir, word-by-word, transliteration, accurate official Mushaf resources only.
4. Account: approved OAuth scopes, bookmarks/notes/collections/goals/preferences/reading sessions, explicit local-cloud merge.
5. Hadith only after source/license approval; Salah and other worship modules follow their own verified source decisions.
6. PWA/offline only within current Foundation permissions, then accessibility/security/performance/SEO/browser hardening.
