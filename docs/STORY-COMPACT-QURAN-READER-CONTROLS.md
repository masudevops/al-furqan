# Story — Compact Quran reader controls

## User outcome

As a mobile Quran reader, I want the reading controls to occupy less vertical space so I can reach the Ayahs quickly while retaining access to all reading and study options.

## Acceptance criteria

- [x] Keep only Ayah navigation and the Reader Settings trigger in the primary toolbar.
- [x] Move translation, reciter, Arabic script, and Tafsir source into Reader Settings.
- [x] Keep Word by word, Tafsir, Memorize, and Introduction as direct study actions.
- [x] Group Mushaf, Quran structure, and Lessons & reflections under a compact More menu.
- [x] Collapse the Tajweed legend into an optional color guide.
- [x] Preserve all existing local preference behavior and dynamically discovered resources.
- [x] Keep controls keyboard accessible and responsive on mobile.
